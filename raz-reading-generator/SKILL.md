# RAZ 分级阅读内容生成

为用户的主题和级别创作适合儿童阅读的**原创**英文内容。定位项目根目录的 `RAZ_Levels_Index_Cards.md`，读取对应级别卡和开头的证据、统计口径及使用说明；不要将本地经验指标宣称为官方定级或认证。接受 aa、A–Z、Z1、Z2，规范化大小写；缺少主题或级别时先询问。仅有 D–I 经本地材料核对，aa–C、J–Z2 沿用旧估计，须在交付时简短标明“该级别尚未用本地书本核对”。

用户给出单个英文单词作为主题时，默认让该词以原样自然出现在**正文**中，不能仅出现在标题、问题或插图建议中，也不能只用同义词代替；用户明确指定词形、用法或不要求原词时遵从用户。主题须与人物行动、关键事件或正文解释的概念有可理解的联系，不能仅孤立地插入主题词；不要求每页都重复该词。主题是情境描述时，不强制将描述逐字放进正文。

## 先问清方向

收到新的读物生成需求，**先澄清方向，再动笔**。只询问用户尚未说明、且会影响内容的事项，每轮集中 2–3 个简短问题，必要时用选项降低回答负担：

- 主题、级别及含义：单词的哪个含义或具体情境？写故事、说明文还是其他文体？希望孩子读完理解什么、练习什么？
- 读者与文本：孩子当前阅读情况、独立阅读还是亲子共读，是否有必须使用的词或不想涉及的内容；篇幅未指定时提出对应级别的建议，不重复索要已知信息。
- 成品方向：插画还是照片风格，有无角色或场景偏好，手机阅读还是打印，是否需要封面、理解题或答案。默认美式英语、简单清楚的儿童插画、竖版学生读本，每个正文页一张大图；题答单独交付，避免混入正文页。用户可另行指定英语变体与成品形式。

用简短需求摘要汇总已知条件和建议默认值；关键方向尚未确定时等待回答，不擅自选定文体就生成全文。用户明确说“其余用默认”或已经给出完整方向时直接采用，无须重复询问。用可用的用户输入工具提问；确认美式英语为默认后，后续任务不再反复问方言。

本阶段是确定写作任务，**不等于用户已经确认最终文本**。只修改 skill、检查既有稿件等任务不需要重新询问孩子与题材。

## 任务与协作

1. 主 agent 根据澄清后的主题、级别、文体和特殊要求制定写作任务，默认使用美式英语（`en-US`），避免为凑级别牺牲准确性。把该级别卡中适用的建议词数、文字组织、词汇及句式、图文支持和理解目标传达给写作 agent。故事应有完整小情节；科普要选少量彼此相关的事实逐步展开，控制陌生概念的累积，必要的新术语首次出现时用上下文或插图解释。对一般性陈述、术语定义及“所有、必须”等概括逐条核实适用范围，并检查前后是否矛盾。不要照搬或改写某本已有 RAZ 书的原文、角色和独特情节。
2. 常规生成启用并复用**恰好两个**子 agent：一个专门写作/修订正文；一个独立审查正文和阅读问题。两个角色不能由同一 agent 兼任。用户要求匿名盲测时，按下方流程另启不继承历史的独立裁判；裁判不兼任写作或级别评审。主 agent 制定写作题目，收到正文后自行拟题，至少包含 3 道适合对应级别、可从正文回答的简短理解题和参考答案；用户明确要求不出题或指定题数时遵从用户。问答与正文分开，避免泄露在正文中。
3. 按下方口径独立统计正文词数、组织及页数，将用户给定的主题原词、其他要求、正文及题目一并交给评审 agent，不让评审从正文猜测主题。交稿后封存该版本的正文、画面说明和题答；修订另存新版本，不能在评审期间覆盖已交稿文件。要求其逐项列出证据、硬性问题、需修订处和结论。主 agent 复核实际最终版本、计数和题答与评审材料一致，不以分数代替判断。
4. 未通过时，将明确问题返回写作 agent 修订；主 agent 必要时同步修订题目，再送同一个评审 agent 审核完整版本。普通生成使用**首次生成加最多 3 次修订**；按用户要求进行多轮盲测优化时，遵守下方最多 3 轮盲测的上限，并在每轮盲测前最多作 2 次质量修订。达到相应上限仍不通过则说明剩余问题，不得声称已通过；每次审查均针对实际最新版本，最终改动不得跳过复审。

如运行环境不支持或不允许启动子 agent，明确告知用户该限制，改为主 agent 自行写作和独立分阶段自评，不得谎称已启用或完成独立评审。默认不向子 agent 指定特定模型，除非上层或用户要求。

## 地道英语专项审校

写作以英语母语儿童读物中自然的表达为目标，默认统一美式拼写、词义、搭配、标点与日常对话用法。避免从中文逐句翻译；不把语法正确自动等同于地道。专有名词和明确引用保留原有写法，不机械替换字母或词语。

独立评审 agent 在级别评审之外，单独审查**标题、逐页正文、理解题和答案**：词语搭配是否自然、人物在该情境下是否会这样说、代词和冠词是否清楚、时态和英语变体是否一致、是否有翻译腔或成人讲课式口吻。朗读检查节奏；为每个需要修改的问题提供页码、原句、建议及理由，保存 `language-review.json`，给出 `PASS` 或 `REVISE`。不得只写“像 native speaker”而不给证据。

地道性须与阅读级别同时成立：低级别自然重复、简单句和清晰命名可以保留；不要为了显得地道而加入生僻习语、复杂句或打散 D 级句架。语言修改回到写作 agent，主 agent 重数正文并核对主题、重复、分页和题答，再由同一评审审完整新版本。语言专项未通过，不提交为可配图的定稿。

交付可以说明“已通过美式英语自然度与级别审校”，准确记录实际由 AI 或真人完成的审校。未发生真人母语编辑审阅时，不声称“母语者撰写/认证”或保证所有母语者都会认可。

## 文本确认后生成图片与 PDF

文本、题答和语言专项均通过后，先展示**完整英文标题、逐页正文、词数、题答及简短画面计划**，说明拟采用的成品形式，请用户确认这一具体版本。此时可准备文字分镜和图片提示词，**不调用图片生成，不生成正式 PDF**。文本确认必须来自看到具体版本后的明确回复；“继续写”“按这个主题做”、沉默或仅通过 agent 评审不等于确认。

收到“文本确认，开始配图/生成 PDF”等明确回复后，按[图片与 PDF 制作流程](references/illustrated-pdf.md)记录该版本的用户确认和内容摘要，再生成逐页原创大图、排版与检查。文字或分页在确认后改变，先复审并重新确认；不能在排版时悄悄润色、删句、缩写或换页。图片修改不改变已确认文字时，无需重复确认文本。

每个正文页对应一张实际独立生成的大图，图像和文字分别排版，保持角色、物品、场景与科学信息一致。参考本地 RAZ 书页的图文比例、清楚留白、大字号和页码安排，使用原创图像、书名及版面，不放官方 Logo 或暗示官方出版认证。常规图像/PDF检查可复用原两个子 agent 的职责，由主 agent负责工具调用和最终核对。

用户只要文本时，完成文字交付即可；用户确认文本并要求继续制作时，不再增加逐张图或每一步的重复批准。图片工具不可用或生成未完成时说明具体缺项，不把提示词、占位图或测试素材当正式成品。

## D 级：默认使用高重复句架

本项目的 D 级视频中，有不少书通过跨页重复句架、只更换少量词语来提高可预测性；故事型书也有重复较少的例子。以下是为满足本项目写作要求设置的**默认目标**，不是 Learning A-Z 的官方统一定级门槛。

- 动笔前选定一个适合主题的简单重复句架或固定短句，并标出拟重复的页码。默认 8–10 页时，让它贯穿**至少 5 个不同正文页**；在重复处或紧邻的句子中至少呈现 3 个不同、与主题或情节有关的信息变化。重复应帮助读者预测并推进内容，而不是把无意义的同一句机械凑满页面；开头、结尾可自然变化。
- 写作子 agent 交稿时指出重复句架、涉及页码和变化内容。主 agent 与评审子 agent 对照正文分别核查；评审报告必须给出句架与页码，而不仅说“重复了关键词”。句架须保留儿童能辨认的具体固定词序，只替换少量明确词槽；不能仅凭同一名词、主题词，或把不同句子泛化成“主语＋动词＋宾语”来认定重复。
- 根据内容选择重复的具体短句、完整句，或在固定词序中设置少量明确词槽的句架；不要求每页逐字相同，也不要仅凭是否有连续三个相同单词判断重复是否达标。重复应可由儿童识别，且仍满足上述跨页及信息变化目标；不要把某一本原书的单一重复方式套用于所有故事。
- 默认目标未达成则反馈修订；若用户明确要求低重复、另一种篇幅或文体无法自然适用，遵从用户并说明取舍。不要为了达标损害事实、故事逻辑或表达自然度。
- 重复应服务于角色的行动、观察或内容推进。对故事，检查替换的词及其相邻句是否让读者看到新的行动、尝试、发现或结果；不要仅为凑页数轮换同义动作或颜色、对象名称。以清单为内容目标的读物、诗歌或科普可以自然使用清单，不强制加情节或反转。故事的结尾可以回扣情境、自然转折或引出新问题；结合上下文和插图判断其是否有意义，不要只因末页出现新对象就判不合格，也不要为了凑整齐的结尾强加无关动作。这是写作建议，不是对原书结构的统一断言。
- 对话和跨页叙事中，让人物、地点与代词指向容易跟上；多个对象接连出现时，必要时重复具体名词，避免 `it` 连续换指而要求儿童自行猜测。不禁止自然、明确的代词。
- 检查相邻页人物和关键物品的位置、必要的移动、事件因果以及结尾是否连贯；作为线索出现的物品应对情节有作用，避免留下影响理解的矛盾或未交代关系。保持单一清楚的目标，不要为了增加情节变化堆砌需要多次空间推断的道具或动作。无需把每个动作都写出来；依靠插图理解时，应在插图建议中写明相应信息。

## 质量评测与按需盲测

常规生成以本 skill 的内容质量、级别适合性和题答依据作为评审目标。增强澄清、确认或制作能力时，验证实际流程与工具；比较写作方法或声称质量改进时，读取[固定质量评测方法](references/quality-evaluation.md)：冻结旧版、任务、对照和量表，比较匿名版本，允许平局，并检查评审稳定性。默认最多 3 轮，用户指定上限时遵从；有益方法应由相同任务条件下的内容证据支持，不以增加规则或改稿次数表示进步。

用户要求的来源辨认仍可作为辅助检查，按上述参考中的封存、随机混排与新裁判流程执行；不能以裁判没选中生成稿作为质量通过或优化停止条件，也不能声称无法识别或得到官方定级。把裁判理由区分为可核实问题、图文支持、主观偏好及错误推断，仅就有依据的问题修订；不得为误导裁判牺牲主题、重复度、自然表达、事实或原创性。缺少合适原书或无法启动独立裁判时，明确标记相应验证未完成。

## 评审与计数

- 通过条件：主题和要求得到满足；内容原创、事实基本准确、儿童适宜且语法自然，英语自然度专项为 PASS；正文词数符合该级卡生成目标，或属于用户明确要求、评审认可且已解释的合理偏离；词汇、句式、重复度、结构和图文支持整体适合级别；D 级应检查上方跨页重复目标及其例外，以及重复变化的作用和跨页人物、代词、空间与事件衔接；专门术语和背景知识的累积不应因词数合格而被忽略；每题及答案都能从正文得出。定量指标是工作目标，不代表官方定级，句长无需每句硬卡上下限。
- 题材确实需要偏离建议值时，由评审说明原因；如果用户明确指定长度或格式，以用户要求为准，同时说明与级别目标的冲突。aa–C、J–Z2 的旧卡在定性与定量方面均未核实，不得把词数、页数、章节、句式或词汇量当官方硬门槛；明确标为近似，并结合其他可靠依据及实际读者调整。
- 将**仅含正文**的 UTF-8 文本写入临时文件：每页用 `## Page 1`、`## Page 2` 等单独成行标记；不放标题、题目、答案、翻译或插图说明。执行 `python3 <本 skill 目录>/scripts/count_reading.py <临时文本文件>` 得到词数及每页词数；英语词、缩写和连字符复合词各按一个词计算，数字按一个词。无须为了字数损害流畅性。句长和句式由评审结合正文人工复核。
- 文本阶段提供正文之外的画面建议，交付英文标题、分页面正文、默认 3 道英文理解题、简洁答案、目标级别、正文词数及语言审校结论，供用户确认。制作阶段交付经渲染检查的 PDF、逐页图片和可编辑文本；题答默认单独交付。用户只要纯文本或有其他明确要求时遵从。没有明确要求时不要附逐句翻译。

## 持续改进

逐轮依据评审意见调整生成要求和内容；若测试揭示可复现的通用流程缺陷，在用户授权范围内最小修改本 skill，再重测受影响案例。不得为通过测试擅自放宽指标或修改样本数据。普通生成过程中若无权限写入 skill，继续完成内容并说明无法持久化改进。
