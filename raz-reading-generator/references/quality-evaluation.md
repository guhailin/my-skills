# 固定条件下检验 skill 改动

仅在用户要求优化或比较 skill 表现时使用。普通生成按入口中的写作与质量评审流程执行。目标是提高当前儿童读物任务的质量，不以让裁判猜错作者来源作为通过条件。

## 先冻结，再比较

1. 保存旧 skill、待检验改动、指标卡、任务和量表的快照。用 2–3 个固定主题，明确级别、文体、篇幅、重复目标、输出格式及插图说明的范围；新旧版本使用相同条件。至少保留一个此前未测试的题目，不根据结果临时替换。
2. 一次检验一项关键方法或事先说明的关联方法组，不同时调整词数、重复目标和题目。两位写作 agent 使用相同类型模型、独立上下文，分别读取各自版本，不能读取另一版稿件或评审意见。主 agent 统一负责题目和答案。
3. 原书可作为结构正例：用用户提供或可合法使用的内容，分析固定语言、每页新信息与画面作用，勿复制角色、独特表达或把整本原书换词改写。参考正例能否帮助写作也需要验证，不默认增加材料一定有效。
4. 比较时提供一致的正文分页、问题答案和每页画面说明；不能一版有图文支持、另一版只有文字。没有实际图片时，只能评价预期图文分工，不宣称验证了真实图片或儿童阅读体验。

## 主评审：读物质量

至少两位不继承写作历史的新评审使用同一量表，对版本匿名编号并随机顺序；不告诉它们哪版新、哪篇原书，也不要求识别 AI。以下维度可各用 1–5 分，但必须有具体页码证据：

- 英语自然与儿童视角：人物的话与行动是否适合情境，表达是否自然清楚。
- 重复的可预测性与作用：稳定结构是否帮助预测，变化是否承载内容；高重复本身既不加分也不扣分。
- 分页信息与节奏：每页的新信息或有意义的预期是否适量；不为凑页拆散微小动作，也不强制复杂情节。
- 事件连贯与图文分工：人物、对象、关键因果是否容易跟上，画面是否具体支持理解；不要要求文字复述图中一切。
- 初级阅读负担：词汇、句法、背景知识和信息密度是否得到上下文支持；没有读者实测不设统一生词上限。

主题原词、正文计数、重复页码及题答依据作为单独任务检查，不用次数合格代替质量。比较允许平局；微小分差且没有决定性内容证据时不得强行选出胜者。

可混入完整原书作质量锚点，观察评审是否只因规律、清单或简单词句而扣分；原书也不是必须满分。另放一篇完全重复的匿名样本检验稳定性：预先约定容差，例如每维差不超过 1、总分差不超过 2；失败的评审结果应保留并报告，不能独自支撑采用结论。原书与新稿比较应优先匹配级别、文体、正文页数和长度，不删改原书凑条件。

先约定采用条件、允许的修订和上限，再看结果。相同模型、多次生成和小样本并不等于统计独立；用偏好与具体缺陷说明结论，不将小样本总分当作官方定级或整体效果证明。候选方法未获支持时保留旧版，不为宣布进步强行采用。

## 辅助检查：来源盲猜

用户要求时可做额外匿名来源辨认，D 级 8 页已有项目脚本 `RAZ_样本分析/盲测/prepare_blind.py`（6 篇原书 + 1 篇生成稿）与 `prepare_pair.py`（1 篇原书 + 1 篇生成稿）。脚本只检查分页/来源标记并混排，不校验转写、实际级别或启动裁判；其他级别须准备对应级别的完整对照。

使用新的无历史裁判，只给中性路径下的匿名正文；答案单独保存并记录摘要，判决保存后才解封。除非实际配置了隔离，不称作操作系统级限制。分别报告七选一和二选一结果，不能混算准确率。集中错选某本原书时记录干扰因素；若变更对照，必须在下一次作答前说明，并保留旧结果。

来源猜对或猜错不等于读物好坏，也不直接触发修订或成为优化停止条件。只将理由中能够对照正文、画面或事实核实的问题返回写作 agent；“像 AI”“太整齐”等不能单独作为改稿指令。
